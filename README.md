新增菜品批量删除功能：提供 DELETE /admin/dish?ids=1,2,3 接口，Controller 用 @RequestParam("ids") 接收前端传来的 id 集合交给 DishService；Service 的 deleteDishById 方法加 @Transactional，把业务校验和删除放在同一个事务里，删除前先做两道校验——先遍历 id 判断菜品是否处于起售状态，是则抛 DeletionNotAllowedException 提示"起售中的菜品不能删除"，再遍历判断菜品是否被套餐关联（查 setmeal_dish 表），被引用则抛异常提示"当前菜品关联了套餐,不能删除"；校验通过后不再逐条删除，而是由 DishMapper.deleteByIds 和 DishFlavorMapper.deleteByDishIds 各执行一条 `delete ... where id in <foreach>` 的批量 SQL，一次性删除菜品及其关联的口味数据，把原来的 2N 条删除 SQL 降为 2 条
