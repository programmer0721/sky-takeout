新增菜品分页查询功能：提供 GET /admin/dish/page 接口，按 page、pageSize、name、categoryId、status 查询，Controller 把 DishPageQueryDTO 交给 Service，Service 先用 PageHelper.startPage(page, pageSize) 开启分页，再调用 DishMapper.pageQuery 查询，最后用 PageResult 返回总记录数和当前页数据；Mapper 的 XML 用一条 dish 左连接 category 的 SQL 同时取出菜品信息和分类名称（c.name as categoryName 映射到 DishVO.categoryName），并用 `<where>` 配合三个 `<if>` 实现动态条件：菜品名称模糊匹配、分类 id 和状态精确过滤，`<where>` 会自动去掉多余的 and、条件都不传时自动省略 where，结果按 create_time 倒序返回
